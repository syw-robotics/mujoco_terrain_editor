# MuJoCo Terrain Editor

纯前端 MuJoCo 地形编辑器。通过 Web 3D 界面组合方块、斜坡、楼梯和平台，并导出可直接加载的 MJCF XML。

## 启动

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 使用方法

1. 从左侧组件库拖拽地形到视口；双击组件可添加到原点。
2. 点击地形后，使用顶部工具移动、旋转或缩放；右侧面板可精确编辑尺寸和变换。
3. 默认启用“自动贴地”，地形底面会保持在 `Z = 0`；取消勾选后可自由编辑高度。
4. 编辑 `Geom 名称`，该名称会直接用于导出的 MJCF `<geom name="...">`。
5. 点击“导出 XML”下载 `terrain.xml`。

快捷键：`W` 移动、`E` 旋转、`R` 缩放、`Delete` 删除、`Ctrl+D` 复制、`Esc` 取消选择。

## 编辑约定

- 使用 Z-up 右手坐标系，长度单位为米，角度单位为度。
- 变换步长：移动 0.05 m、旋转 1°、缩放 0.1。
- 变换手柄位于元素几何中心，并使用元素局部坐标。
- 名称仅使用 ASCII 字母、数字、下划线、连字符和点，以保证 MJCF 兼容性。

## 地形参数

- 斜坡：坡面宽度、水平长度、坡度。
- 楼梯：踏步宽度、踏步长度、踏步高度、级数。
- 平台：平台宽度、长度、高度。

默认尺寸和新地形类型统一定义在 [`src/data/presets.js`](src/data/presets.js)。修改参数的 `default` 即可更新默认尺寸；新增由 box 组合的地形，只需添加一个 `defineTerrainPreset` 配置，组件库、属性面板、自动贴地和 XML 导出会自动接入。
